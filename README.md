2D Survival Game

A solo-developed 2D survival game built in Unity — dodge incoming obstacles for as long as you can.

Demo

[![DEMO](https://youtu.be/jBtvnJZ1oj4/0.jpg)](https://youtu.be/jBtvnJZ1oj4)

Overview

Class project (March 2026). The player survives against randomly spawned obstacles for a randomized time window — no two runs last exactly the same length.

Features
Jump physics and collision detection
Pseudo-random obstacle/object spawning
Parallax-scrolling backgrounds
Full gamepad support
Tech Stack

Unity, C#

Role

Solo project — designed and implemented end-to-end.
